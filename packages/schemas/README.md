# @kyuworks/schemas

The Kyu message envelope, naming rules and schema adapters. Runtime-light; depends on Zod only.

```bash
pnpm add @kyuworks/schemas
```

Most projects install [`@kyuworks/sdk`](https://www.npmjs.com/package/@kyuworks/sdk), which brings this package at the same version. See the [Install section of the repository README](https://github.com/kyuworks/kyu#install).
