# @kyuworks/sdk

The Kyu client SDK: publish through a transactional outbox, subscribe with Hatchet, run durable handlers. It ships the outbox SQL migrations in `migrations/`; apply them with your own migration runner.

```bash
pnpm add @kyuworks/sdk
```

See the [Install section of the repository README](https://github.com/kyuworks/kyu#install) for the pnpm 11 release-age setting and how to apply the migrations.
